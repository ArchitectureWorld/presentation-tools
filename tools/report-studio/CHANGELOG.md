# Changelog

本项目遵循语义化版本号。当前发布版本为 `0.8.1`。

## 0.8.1 — 2026-09-02

- 将 Agent 金色全息能量核心图标压缩为透明 WebP，并通过 CSS 单次嵌入、多个位置复用。
- 修复单文件因重复 Base64 资源导致体积过大、当前会话内嵌预览无法稳定加载的问题。
- 单文件构建产物由约 7.04 MB 降至 212,919 bytes。
- 新增发布预览体积测试：单文件必须低于 1 MB，Agent 图标数据资源只能嵌入一次。
- 保持 `0.8.0` 的悬浮入口、拖动吸附、项目级连续会话和批注批次联动行为不变。

## 0.8.0 — 2026-09-02

- 悬浮 Agent、聊天窗口标题图标和 Agent 消息头像统一替换为金色全息能量核心视觉。
- 保持原有 Agent 交互和业务逻辑不变。

## 0.7.0 — 2026-09-02

- 悬浮 Agent 图标支持自由拖动、左右边缘吸附和位置记忆。
- 大纲、草案和排版统一使用一个项目级连续 Agent 会话。
- 聊天窗口实时显示当前阶段和当前页面。
- 批注批次的“提给Agent”接入同一会话时间线。
- 会话内新增“系统 · 批注批次”消息，可定位回右侧对应批次。
- Agent 返回结果同时保留在项目级聊天会话和原批次中。

## 0.6.0 — 2026-09-02

- 新增独立悬浮 Agent 入口。
- 点击后打开约 80% 屏幕的聊天窗口。
- 支持普通消息发送、模拟回复、新建对话、关闭和当前页面/阶段提示。

## 0.5.0 — 2026-09-02

- 草案阶段“文字内容”新增人工直接编辑模式。
- 页面标题、正文、正文要点、关键指标和讲解脚本均可直接修改。
- 编辑模式提供“保存修改 / 取消”，支持 `Ctrl/⌘ + Enter` 保存和 `Esc` 取消。
- 编辑期间暂停文字拖选批注，并阻止未保存状态下切换页面或阶段。
- 保存后更新结构化页面数据并持久化，同步排版阶段对应文字且保持元素几何不变。

## 0.4.1 — 2026-09-02

- 修复受限预览环境中批注“编辑”按钮无响应的问题。
- 移除 `window.prompt`，改为批注卡片内联编辑。
- 已完成批注修改后自动恢复为未完成状态，并继续保留在原批次。

## 0.4.0 — 2026-09-02

- 右侧批注栏拆分为固定标题/筛选区、独立滚动批次区和固定输入区。
- 批次列表增加显式滚动条、上下阴影提示和作用域级滚动位置恢复。

## 0.3.0 — 2026-09-02

- 批次标题新增 `已完成 x · 未完成 x`。
- 移除全局 Agent 提交按钮，改为每个批次独立显示 `提给Agent`。
- 历史批次支持继续补充、编辑和完成状态切换。
- 历史批次再次提交时保留原 `roundId`，仅发送未完成内容。

## 0.2.0 — 2026-09-02

- 批注按轮次和时间归档。
- 本轮未提交置顶展开，处理中自动展开，历史批次默认折叠并倒序排列。
- 点击上脚标自动展开所属批次并定位。

## 0.1.0 — 2026-09-02

- 建立大纲、草案、排版三阶段可运行交互原型。
- 实现“添加批注”和批次级“提给Agent”两类操作。
