# Report Studio v0.8.1 Release Notes

发布日期：2026-09-02  
发布类型：可运行交互原型基线

## 交付结论

`v0.8.1` 是当前唯一有效的交互原型发布版本。它完整保留 `v0.7.0` 的项目级悬浮 Agent 与批注批次联动能力，并修复 `v0.8.0` 因 Agent 图标资源重复内嵌造成的单文件体积膨胀和会话内预览加载问题。

## 关键能力

- 大纲、草案、排版三阶段工作台。
- 大纲级与页面级批注作用域隔离。
- 批注按轮次折叠、统计、独立滚动和批次级“提给Agent”。
- 草案文字内容人工编辑及排版文字同步。
- 图片、视频、图表统一素材层级及缩略图预览。
- 可拖动、左右吸附、位置记忆的悬浮 Agent 图标。
- 项目级连续 Agent 会话。
- 普通聊天与批注批次提交进入同一会话时间线。
- 会话中的批次消息可定位回右侧原批次。

## v0.8.1 修正

- Agent 图标改为单份透明 WebP 数据资源。
- HTML/CSS/JS 中不再重复嵌入同一图像。
- 单文件构建产物体积：`212,919 bytes`。
- 新增自动化约束：
  - 构建产物小于 `1 MB`；
  - Agent 图标数据资源只允许出现一次。

## 非正式能力

以下内容仍为 Mock 或尚未接入正式链路：

- Agent 回复为本地模拟逻辑，不调用真实模型。
- Project State 使用浏览器本地存储，不是 DSH Storage。
- “提给Agent”未转换为正式 DSH Command。
- Agent 返回未进入正式 Revision、差异预览和批准流程。
- 素材 AI 生成、PPTX/PDF/HTML 报告导出仍未接入正式生产实现。

## 下一实施门槛

正式开发前，需要隔壁架构完成并冻结“最小架构基线”，至少明确：

1. Studio Document 与现有业务状态的映射；
2. 稳定 ID 体系；
3. 批注、轮次、提交和 Agent 消息的数据合同；
4. 当前 DSH Session 与项目级 Agent 会话的绑定方式；
5. Agent Command、Revision、预览与应用机制。
